Triple Espresso
Descripción del proyecto

Triple Espresso es una página web para una cafetería llamada Triple Peaks. El proyecto presenta información sobre la cafetería y su zona de estudio, además de permitir a los usuarios reservar una mesa mediante un formulario y acceder a las redes sociales desde el pie de página.

La página está estructurada en diferentes secciones, incluyendo el encabezado, la sección de reserva y el pie de página.

Tecnologías y técnicas utilizadas

- HTML5: para crear la estructura y el contenido de la página.
- CSS3: para los estilos, colores, tamaños, posiciones y distribución de los elementos.
- Flexbox: para organizar y alinear elementos, especialmente en el encabezado y el pie de página.
- BEM: para nombrar y organizar las clases CSS de manera clara y consistente.
- Pseudoclases ":hover": para crear efectos interactivos en los enlaces de navegación, el botón del formulario y los enlaces de redes sociales.
- Google Fonts: para utilizar las tipografías Inter y Noto Serif.
- Formularios HTML: para crear el formulario de reserva de mesas y aplicar validaciones básicas, como establecer un mínimo de 1 y un máximo de 8 comensales.
- Navegación: mediante enlaces internos utilizando id y enlaces con # para desplazarse entre las diferentes secciones de la página.
